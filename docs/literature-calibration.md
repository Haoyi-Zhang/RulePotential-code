# Full-paper literature calibration

This matrix closes the manuscript-planning calibration specified for the internal AIJ research draft. It records targeted full-paper reading, not a claim that every line was read or that citation counts measure quality. Counts are used only to calibrate bibliography breadth; scholarly relevance controls inclusion.

## Reading and use boundary

Each record identifies the parts inspected: problem framing, formal model or mechanism, principal proof/performance argument, practical connection, evaluation or examples, conclusion, bibliography, and figure/table roles. The calibration informs exposition and claim boundaries; it does not import theorem statements beyond passages separately cited in the manuscript and source ledger. No paper PDF is redistributed in the artifact.

The resulting manuscript pattern is: begin with a concrete update failure; declare the exact state and trust contract; separate exactness, representation, selection, and repair theorems; pair asymptotic arguments with explicit negative controls; and close with one consolidated boundary section. Figures are reserved for the running exchange example, a representability obstruction, and measured interface costs; tables summarize obligations and evidence rather than decorate the paper.
